# 术语表 · 简体中文（zh-Hans）

> 本表是 `data/i18n/zh-Hans/` 语言包的强制用词表。任何译者、任何自动化流程在翻译前都应先读本页。
> 目标是让同一个英文概念在 1912 个知识点、177 个领域概览和 1097 条教学研究中只对应一个中文说法。

## 0. 通用约定

| 项目 | 约定 |
|---|---|
| 语言 | 简体中文（zh-Hans），面向中国大陆小学（6–12 岁）家长与教师 |
| 人称 | 面向孩子时用"你/孩子"；面向家长时用"孩子"；面向教师时用"教师" |
| 语气 | 平实、具体、可执行；避免口号式表达与营销腔 |
| 句式 | 英文长句拆成中文短句；保留原文的因果与顺序，不省略限定条件 |
| 标点 | 使用中文全角标点；英文专有名词与代码保留半角形式 |
| 数字 | 保留阿拉伯数字；数学数值、公式、单位保留半角写法 |
| 占位符 | `{{name}}` 必须原样保留，数量不得变化 |
| 课程代码 | `4-PS4-1`、`AC9TDE2P04`、`ON-MATH-2020-G1-C3.1` 等必须逐字保留 |
| 年级/学段 | 保留体系语境：英国 "Year 4" → "四年级（英国）"；加拿大 "Grade 3" → "三年级（安大略）"；印度 "Class III" → "三年级（CBSE）"；"Foundation Stage" → "基础阶段" |
| 引用 | 英文教材原文引用可译为中文，但不得改变其含义；被省略的课标原文标记 `[curriculum wording omitted; reference X]` 保持原样不译 |
| 括号 | 原文中的英文补充说明，译为中文；专有名词括注可保留英文原名，如"位值（place value）"仅首次出现时使用 |

## 6. 保留不译的内容

以下内容必须逐字保留，不翻译、不改写、不省略：

- 知识点 id（`mt_…`）、先修知识点 id、课程条目代码（`4-PS4-1` 等）
- 评测方法枚举值：`two_tier`、`performance_task`、`interpret_translate`、`use_in_context`、`open_epistemic_probe`
- 错误类型枚举值：`misconception`、`myth`、`developmental`、`interference`、`performance`
- 置信度枚举值：`high`、`medium`、`low`
- 依赖强度枚举值：`hard`、`soft`
- 学科与领域英文键名（语言包中的 `subject`/`domain` 字段保持英文，译文放在 `labels.json`）
- 网址、出版物名称（如 "Eureka Math 2018"、"NGSS"）、作者名
- `{{name}}` 占位符
- 被省略课标原文的标记，如 `[curriculum wording omitted; reference 4-PS4-1]`

## 7. 翻译自检清单

每个分片交付前，译者需逐条确认：

1. 行数与分片源文件一致，数组长度与英文一一对应。
2. 每个字符串都含中文，没有残留整段英文。
3. `{{name}}` 数量未变。
4. 课程代码、年级体系标识、枚举值全部原样保留。
5. 术语与本表一致；多义词按第 5 节处理。
6. 数字、公式、单位、年龄区间未改动。
7. 语气面向小学生家长/教师，可执行、不夸大。
