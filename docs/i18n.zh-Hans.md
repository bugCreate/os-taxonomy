# 本地化（i18n）

本数据集以英文发布。**语言包（locale pack）** 让新增一种语言无需改动任何英文数据文件：英文图谱仍是 id、依赖边与课程代码的唯一事实来源，语言包只保存与标识符一一对应的译文。

```
data/i18n/zh-Hans/topics.json            # 知识点名称 / 描述 / 掌握证据 / 评估提示
data/i18n/zh-Hans/clusters.json          # 领域概览
data/i18n/zh-Hans/dependencies.json      # 依赖理由
data/i18n/zh-Hans/teaching-research.json # 教学研究（教学法 / 学习活动 / 评测）
data/i18n/zh-Hans/labels.json            # 学科、领域、类型等标签
data/i18n/zh-Hans/manifest.json          # 语言包清单与校验和
```

英文版说明见 [docs/i18n.md](i18n.md)，术语表见 [docs/i18n/glossary.zh-Hans.md](i18n/glossary.zh-Hans.md)。

## 为什么采用平行语言包

* **英文文件逐字节不变。** `data/topics.json` 等文件的知识点 id、依赖边、课程代码与清单校验和都不动，下游消费者无需任何改动。
* **按 id 关联。** 关联键只有四个：`topic.id`、`topicId`、`prerequisiteId`，以及领域概览的 `(subject, domain, ageRangeStart)`。
* **覆盖率可度量。** 语言包要么完整，要么不完整；校验脚本会明确指出缺哪一行。
* **语言之间互不阻塞。** 新增语言 = 新增一个目录。

## 翻译范围

| 字段 | 是否翻译 | 说明 |
|---|---|---|
| `topic.name` / `description` / `evidence[]` / `assessmentPrompt` | 是 | `assessmentPrompt` 中的 `{{name}}` 必须原样保留 |
| `cluster.summary` | 是 | 按 学科 + 领域 + 年龄段 关联 |
| `dependency.reason` | 是 | 按 topicId + prerequisiteId 关联 |
| 教学研究中的叙述文本 | 是 | 教学法、学习活动、评测文本、来源主张 |
| `subject` / `domain` / `type` / `strength` / `method` / `kind` / `confidence` | 否 | 稳定键值；中文措辞放在 `labels.json` |
| 知识点 id、课程代码、网址、出版物名称 | 否 | 必须逐字保留 |
| `data/curriculum-standards.json` | 否 | 外部课标原文受上游许可约束，保持原样 |
| `provenance`、`publicationNotes` | 否 | 发布元数据，沿用英文文件 |

## 校验规则

`scripts/check-i18n.mjs` 是唯一的关卡。以下情况一律判定为不合格：

* 缺少某个知识点 / 领域概览 / 依赖边 / 教学研究记录，或出现英文数据集中不存在的 id；
* 改动了课程代码、评测方法、错误类型、前置知识点 id、网址或置信度；
* 平行数组长度发生变化，或 `{{name}}` 占位符数量发生变化；
* 字符串不含中文，或大段英文原样残留；
* 译文长度异常（英文 ≥ 20 字符时，低于 0.12× 或高于 4×）；
* 与 `data/i18n/<locale>/manifest.json`、`data/manifest.json` 中记录的校验和不符。

`npm run validate` 会对每个语言包执行以上检查，译文出错与依赖边出错同样会导致校验失败。

## 常用命令

```sh
npm run i18n:shards zh-Hans     # 把英文数据切分成翻译分片
npm run i18n:merge zh-Hans      # 把译文分片合并成语言包
npm run i18n:check              # 校验全部语言包
npm run i18n:build zh-Hans      # 生成面向应用的 dist/zh-Hans/
npm run i18n:verify <分片 id>   # 校验单个分片（译者自检用）
```

`npm run i18n:build` 输出的 `dist/<locale>/` 中，每个被翻译的字段承载中文内容，英文原文保留在同名字段的 `<field>En` 旁，应用可据此一键切换语言。

## 新增一种语言

1. `npm run i18n:shards <locale>` — 生成 `work/i18n/shards/*.json` 与计划文件 `work/i18n/plan.json`。
2. 把每个分片翻译为 `work/i18n/out/<分片>.json`：JSON 数组，行数、顺序、键名与源文件一致。
3. `npm run i18n:merge <locale>` — 写入 `data/i18n/<locale>/` 并刷新 `data/manifest.json`。
4. 编写 `data/i18n/<locale>/labels.json`（学科、领域、类型）与 `docs/i18n/` 下的术语表。
5. `npm run i18n:check && npm run validate && npm test`。
